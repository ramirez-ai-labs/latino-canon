## **Decision Criteria Checklist**

Use this for each film:

```
✓ Heritage: Director/writer is Latino or diaspora filmmaker
✓ About community: Centers Latino characters/community experience
✓ Breakthrough: First achievement, award, representation milestone
✓ Critical acclaim: Top-tier film festival, major award nomination
✓ Scholarship: Academic references, cultural impact
```

**Quick scoring:**
- 3+ ✓ → **ADD to canon**
- 2 ✓ + strong fit → **ADD**
- 1 ✓ or marginal → **HOLD** (review later)
- 0 ✓ → **EXCLUDE** (note reason)
